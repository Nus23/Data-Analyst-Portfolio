# Retail Sales SQL Analysis

## Project Overview

This project analyses retail sales data using SQL and SQLite.

The objective is to identify sales trends, customer behaviour, product performance, and regional business insights to support data-driven decision making.

## Tools Used

- SQL
- SQLite
- DB Browser for SQLite
- GitHub

## Dataset

Sample Superstore Dataset

## Key Business Questions

- What is the total sales revenue?
- What is the total profit?
- Which categories generate the most sales?
- Which products perform best?
- Who are the highest-value customers?
- Which regions generate the highest revenue?
- Which customer segments drive sales?

## SQL Skills Demonstrated

- SELECT
- WHERE
- GROUP BY
- ORDER BY
- LIMIT
- Aggregate Functions
- Business Analysis Queries

## Key Insights

- Technology generated the highest revenue.
- High-value customers contribute significantly to total sales.
- Regional performance varies considerably.
- Product and category analysis can support inventory planning and marketing strategies.
