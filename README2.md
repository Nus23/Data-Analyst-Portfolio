# Retail Sales SQL Analysis

## Project Overview

This project uses SQL to analyse retail sales data from the Sample Superstore dataset. The aim is to identify sales performance, profit trends, top customers, best-selling products, and regional business insights.

## Tools Used

- SQLite
- DB Browser for SQLite
- SQL
- GitHub

## Dataset

Dataset: Sample Superstore

The dataset includes order details, customer information, products, categories, sales, profit, region, and segment data.

## Business Questions Answered

- What is the total sales value?
- What is the total profit?
- Which product categories generate the highest sales?
- Which categories generate the highest profit?
- Who are the top customers by sales?
- What are the top-performing products?
- Which regions generate the highest sales?
- Which customer segments perform best?

## SQL Skills Demonstrated

- SELECT statements
- Aggregation using SUM
- GROUP BY
- ORDER BY
- LIMIT
- ROUND
- Working with column names containing spaces
- Business insight generation

## Key Insights

- Sales performance varies by category, region, and customer segment.
- Top customers and top products contribute significantly to total sales.
- Profit analysis helps identify which categories and regions are most valuable.
- SQL analysis can support reporting, business intelligence, and decision-making.
