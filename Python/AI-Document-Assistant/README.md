# AI Document Assistant

## Project Overview

AI Document Assistant is a Python-based application that allows users to upload PDF documents and ask questions about their contents.

The application extracts text from uploaded PDF files, displays document previews, and searches the document to provide relevant answers based on user questions.

This project demonstrates document processing, information retrieval, Python programming, and web application development using Streamlit.

---

## Features

* Upload PDF documents
* Extract text from PDFs
* Preview document content
* Ask questions about uploaded documents
* Retrieve relevant information from document text
* Interactive web interface built with Streamlit
